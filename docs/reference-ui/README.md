# Reference UI

Visual references for the Whiteboard UX direction.

## Slugline references (please add)

The Slugline reference screenshots are **not** committed (they're external,
copyrighted images). To document the target direction locally, place them here:

- `slugline-light.png` — Slugline light mode
- `slugline-dark.png` — Slugline dark mode
- `logosforge-light.png` — current LogosForge Whiteboard, light theme
- `logosforge-dark.png` — current LogosForge Whiteboard, dark theme

These guide the look: a minimal, writing-first app — distraction-free, elegant
light/dark themes, a large comfortable writing surface, a clean left outline,
and no heavy dashboard chrome. We follow this direction without cloning Slugline.
